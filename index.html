01 / About

One coordinated space for the systems inside buildings.

CORE | Building Systems | Vertascan brings conceptual MEP drafting, editable equipment assemblies, building levels, orthographic inspection, quantity takeoffs and network analysis into a browser-based workspace.

The X-ray BIM approach treats architecture as transparent spatial context so the critical distribution systems remain readable during design review.

Work in plan or 3D, review section geometry, evaluate clashes and route assumptions, and generate preliminary documentation and export files. Designed for exploratory coordination and engineering evaluation—not as a substitute for professionally approved construction documentation.

01 / System designation

In Plan, click to place route vertices. Double-click, Enter or Finish ends the route. All dimensions use metres internally.

02F / Custom MEP layouts

Generates editable connected route objects on the active level with current system dimensions and rates. Move or reshape routes in Plan using Edit vertices. Layout JSON excludes non-MEP XREF source files.

02G / External references · XREF

Supported: GLB · glTF with companion assets · OBJ/MTL · FBX · STL · DXF ASCII (LINE, polylines, 3DFACE, CIRCLE, ARC, POINT) · PNG/JPG/WebP/SVG. Select companion files in one picker operation. DXF files in mm normally need scale 0.001.

Source origin remains unchanged unless you choose Center or Bottom Center. Gizmo shortcuts: W move, E rotate, R scale. Hold Shift for grid snapping while dragging.

Import GLB, glTF (+ .bin/textures), OBJ, STL, FBX, DXF (2D/3D supported entities), or image underlays. IFC import: top toolbar.

Select one model and its companion files together for .gltf or .obj materials; transform the imported reference using metres per model unit. DXF entities retain elevations (DXF Z → CORE Y). XREF geometry is read-only and must be reimported after reopening a project.

02C / Connectors, constraints & dimensions

Select equipment and a host route to establish a connector.

Port compatibility uses discipline and nominal connection sizes; transitions are flagged as proposed, not manufacturer-selected. Dimensions store references and regenerate with changes.

02D / Network engineering & reroute

Select a route. Calculations are preliminary steady-state estimates, not verified equipment sizing.

Reroute: 2D A* at the existing elevation, avoiding schematic equipment/other-route footprints; end points remain fixed. Fluid: Darcy–Weisbach using manually entered constant friction factor. Electrical: resistive voltage drop, assumed copper at 20°C; ignores reactance, derating, harmonics and protection coordination.

02E / Connected network solver · v1.9

Select the source route. Endpoints within 0.15 m connect. Assign terminal design demands by route tag (L/s for fluid systems, A for electrical). Tree networks only; cycles and disconnected branches are reported.

Choose a source route to analyze its connected component.

Assumptions: endpoint-only adjacency, steady-state tree, fixed branch demands, constant friction factors, simple quadratic source curve, simplified breaker/voltage screening. Not a code-compliant protection study, equipment selection or certified hydraulic/airflow balance.

02B / Coordinated plans, sections & hosting

True parallel-projection CAD cameras. Plan/section windows filter by world elevation and selected station. Host anchoring follows the nearest point on an MEP route; this is a reference relationship, not fabrication connectivity.

02 / Building levels & CAD grids

Plan drafting uses X/Z coordinates at active level + route offset. Snap combines drawing increments, nearby endpoints and building grid axes. Levels and grids save in .core projects.

02H / CAD coordination drafting

True orthographic model views with editable colour-coded discipline layers. Layer visibility affects the 3D workspace and exported vector drawing.

Native editable MEP geometry is preserved. SVG export uses parallel projection, vector routes and discipline colours; it is not a DWG or fabrication drawing.

03 / Parametric plant & equipment

Each family creates editable schematic 3D geometry, coordinated metadata, quantities and documentation. Not manufacturer fabrication models.

Connection & fabrication parameters

Fittings and junction IDs are inferred from coincident route endpoints and changes of direction. Not hydraulic sizing or verified fabrication spool generation.
